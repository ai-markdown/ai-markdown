## Start exploring

1. **Playground** — edit Markdown and try the renderer's options.
2. **Basics & Customization** — compare syntax, components and rendering policies.
3. **Streaming & Documents** — replay incoming text and follow references across chunks.
4. **Performance Lab** — run measurements in your own browser.

Both catalogs use the same engine, shared core and sample corpus. Each runs its own renderer and browser tests. Performance examples document their environment and are not cross-framework rankings.
